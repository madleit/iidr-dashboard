# Performance Issue
Current dashboard is slow because each endpoint launches:
java -jar chcclp.jar

Optimization strategy:
Create consolidated endpoint:
/dashboard-data

Single CHCCLP execution.
Single Access Server login.

# dashboard_data_raw()
Executes:
- list datastores
- list subscriptions
- monitor replication
- monitor subscription latency
- list subscription events count 10 type source
- list subscription events count 10 type target

# Current Blocking Issue
/dashboard-data returns:
- datastores OK
- subscriptions OK
- monitor OK
- latency OK
- events source EMPTY
- events target EMPTY

# Root Cause Identified
parse_dashboard() was searching for:
list subscription events type source
list subscription events type target

Actual CHCCLP output:
list subscription events count 10 type source;
list subscription events count 10 type target;

Recommended fix inside parse_dashboard():

source_events_raw = extract_section(
    raw,
    "type source;",
    "type target;"
)

target_events_raw = extract_section(
    raw,
    "type target;",
    "exit;"
)
